# MyGigMint – User Stories

**Document Version:** 1.0  
**Document Type:** User Stories  
**Methodology:** Agile Scrum  
**Project:** MyGigMint

---

# 1. Purpose

This document defines how each type of user interacts with the MyGigMint platform. Every story follows the standard Agile format:

> As a <role>, I want <goal>, so that <benefit>.

---

# 2. Guest User Stories

### Registration

- As a guest, I want to create an account using email.
- As a guest, I want to register using Google.
- As a guest, I want to verify my email.
- As a guest, I want to login securely.
- As a guest, I want to reset my password.

### Discovery

- As a guest, I want to browse available jobs.
- As a guest, I want to search jobs.
- As a guest, I want to filter jobs by category.
- As a guest, I want to see earning examples.
- As a guest, I want to view FAQs.

# Acceptance Criteria

Every user story must satisfy:

- Secure authentication
- Fast response time
- Mobile responsive UI
- Proper validation
- Error handling
- Audit logging
- Accessibility support

# Conclusion

These user stories define the expected behavior of every major feature in MyGigMint and serve as the foundation for development, testing, sprint planning, and AI-assisted code generation.
